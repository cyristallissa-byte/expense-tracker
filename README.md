# Expense Tracker

A simple web app to track daily spending.

## Features
- Add, edit and delete expenses
- Categories (Food, Transport, Shopping, Other)
- Date for each expense, newest first
- Monthly view and category filter
- Doughnut chart of spending by category
- Data saved in the browser with localStorage

## Built with
HTML, CSS, JavaScript and Chart.js

## How to run
Download `index.html` and open it in your browser.
